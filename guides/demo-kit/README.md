# CleanScrape demo kit

Two practical demonstrations for tutorials, workshops and technical evaluations. Start with the result someone needs, not a tour of every setting.

**Free materials; paid collection is separate.** The skills, local example and written guides in this repository are MIT licensed. They do not require a new scrape. If you choose to collect fresh data, use your own Apify account, check the current price and set a spending limit first.

## Choose a demonstration

| Audience | Question | Guide |
| --- | --- | --- |
| App developers, product teams, app researchers | What changed between two saved review exports? | [App-review comparison](app-review-comparison.md) |

## A clear walkthrough

1. Explain the question and show the intended output.
2. State whether the data is real, synthetic or an older saved export.
3. Show only the inputs needed for that question.
4. Walk through the result and one important limitation.
5. Link the exact guide and the Actor, with any commercial connection disclosed.

For a free demonstration of the local example, use its built-in synthetic data. No account, token or new Actor run is needed. For a live Actor demonstration, show the chosen cap and actual run cost instead of quoting only a per-1,000 price. Hide credentials, signed download URLs, customer records and unrelated browser tabs.
